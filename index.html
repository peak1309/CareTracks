เชื่อมต่อฐานข้อมูล Cloud (Supabase)

ซิงค์ข้อมูลนักศึกษาและการเช็คชื่อแบบเรียลไทม์ข้ามอุปกรณ์

ขั้นตอนการเชื่อมต่อ Supabase:
  1. สร้างโปรเจกต์ฟรีที่เว็บไซต์ supabase.com
  2. ไปที่เมนู SQL Editor แล้วคัดลอกคำสั่งในไฟล์ supabase-schema.sql ไปกด Run
  3. ไปที่เมนู Project Settings > API แล้วนำ Project URL และ anon public API Key มากรอกในช่องด้านล่าง
