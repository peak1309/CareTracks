# CareTrack Edu — ระบบติดตามนักศึกษาขาดเรียนบ่อยและแจ้งเตือนครูที่ปรึกษา
> **วิทยาลัยการอาชีพเวียงสระ (Wiang Sa Industrial and Community Education College)**
> ระบบเฝ้าระวังและป้องกันนักศึกษาหลุดจากระบบการศึกษา พร้อมรองรับการเชื่อมต่อฐานข้อมูล Cloud (Supabase)

---

## 🎯 วัตถุประสงค์ของระบบ
ระบบถูกออกแบบมาเพื่อช่วยสถานศึกษา วิทยาลัยการอาชีพเวียงสระ ในการ:
1. **ตรวจจับสัญญาณเตือนตั้งแต่ระยะแรก (Early Warning):** ตรวจจับนักศึกษาที่เริ่มขาดเรียนบ่อย หรือขาดติดต่อกัน ก่อนที่เวลาเรียนจะต่ำกว่า 80% (เกณฑ์หมดสิทธิ์สอบ / มส.)
2. **เชื่อมโยงข้อมูลสู่ครูที่ปรึกษาทันที (Instant Advisor Alert):** แจ้งเตือนครูที่ปรึกษาอัตโนมัติผ่านระบบและการแจ้งเตือน LINE Notify ทันทีที่มีการบันทึกการขาดเรียน
3. **ส่งต่อและบันทึกการดูแลช่วยเหลือแบบองค์รวม (Case Care & Intervention):** บันทึกการพูดคุยกับผู้ปกครอง การช่วยเหลือด้านทุนการศึกษาฉุกเฉิน ปัญหาครอบครัว สุขภาพจิต หรือการเรียนซ่อมเสริม
4. **ป้องกันการหลุดจากระบบอย่างยั่งยืน:** ติดตามผลจนกระทั่งนักศึกษากลับมาเข้าเรียนตามปกติ (Resolved Case)
5. **รองรับฐานข้อมูล Cloud (Supabase):** ใช้งานร่วมกันได้หลายอุปกรณ์ ทั้งมือถือและคอมพิวเตอร์แบบเรียลไทม์

---

## ☁️ วิธีการเชื่อมต่อฐานข้อมูล Supabase (3 ขั้นตอนง่ายๆ)

ระบบได้เตรียมสคริปต์ SQL และ UI สำหรับเชื่อมต่อ Supabase ไว้ให้พร้อมใช้งาน:

### ขั้นตอนที่ 1: สร้าง Project ใน Supabase
1. สมัครใช้งานฟรีที่ [supabase.com](https://supabase.com)
2. สร้างองค์กรและสร้าง Project ใหม่ (เช่น `caretrack-wiangsa`)

### ขั้นตอนที่ 2: รัน SQL Schema เพื่อสร้างตาราง
1. เปิดเมนู **SQL Editor** ในหน้า Dashboard ของ Supabase
2. เปิดไฟล์ [`supabase-schema.sql`](file:///e:/งาน%20รพ/supabase-schema.sql) ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมด
3. วางลงในช่อง SQL Editor แล้วกดปุ่ม **"Run"**
   - ระบบจะสร้างตาราง `students`, `attendance_records`, `care_logs`, `alerts` พร้อม Index, RLS Policies และข้อมูลตัวอย่างเริ่มต้นให้ทันที!

### ขั้นตอนที่ 3: นำค่า API มาเชื่อมต่อในหน้าเว็บ
1. ในหน้า Supabase Dashboard ไปที่เมนู **Project Settings** (ไอคอนฟันเฟือง) > **API**
2. คัดลอก:
   - **Project URL** (เช่น `https://abcdefghijkl.supabase.co`)
   - **Project API keys** > **anon public** (เช่น `eyJhbGciOi...`)
3. เปิดหน้าเว็บไซต์ CareTrack แล้วกดปุ่ม **"เชื่อมต่อ Supabase"** ที่แถบเมนูด้านบนขวา
4. วาง URL และ Anon Key แล้วกด **"บันทึกและเชื่อมต่อ"**
5. หากต้องการนำข้อมูลเริ่มต้นในเครื่องขึ้นไปยัง Cloud สามารถกดปุ่ม **"อัปโหลดข้อมูลเริ่มต้นขึ้น Cloud"** ได้ทันที

> **หมายเหตุ:** หากยังไม่ได้เชื่อมต่อ Supabase ระบบจะทำงานในโหมด **Offline / LocalStorage** อัตโนมัติ โดยข้อมูลจะถูกบันทึกไว้ในเครื่องเบราว์เซอร์อย่างปลอดภัย

## ✨ ฟีเจอร์เด่นของระบบ (Core Features)

1. **ภาพรวมความเสี่ยง (Executive & Advisor Dashboard):**
   - KPIs: จำนวนนักศึกษาทั้งหมด, กลุ่มวิกฤต (สีแดง), กลุ่มเฝ้าระวัง (สีเหลือง), เคสที่อยู่ระหว่างดูแล, เคสที่ช่วยเหลือสำเร็จ
   - Urgent Care Queue: เคสด่วนที่ต้องดำเนินการวันนี้ พร้อมปุ่มโทรหาผู้ปกครอง, บันทึกการดูแล และส่ง LINE แจ้งเตือน
   - Interactive Charts: กราฟวงกลมปัจจัยสาเหตุ และกราฟแท่งเปรียบเทียบระดับความเสี่ยงตามแผนกวิชา
2. **รายชื่อนักศึกษาและคัดกรองความเสี่ยง (Student Risk Monitor):**
   - แถบ Progress Bar คำนวณเวลาเรียนสะสมอัตโนมัติ (< 80% แจ้งเตือนสีแดงทันที)
   - ตัวกรองความเสี่ยง: วิกฤต, เฝ้าระวัง, คลี่คลายแล้ว, ปกติ
   - ส่งออกข้อมูลเป็นไฟล์ Excel / CSV ได้ทันที
3. **ระบบเช็คชื่อเข้าเรียนประจำคาบ (Attendance Check-in System):**
   - เช็คชื่อ [มา] [สาย] [ลา] [ขาด] หรือ [มาครบทุกคน]
   - ระบบตรวจจับอัตโนมัติ: หากขาดสะสม $\ge 4$ ครั้ง หรือขาดติดต่อกัน 3 วัน จะส่งสัญญาณเสียงและแจ้งเตือนครูที่ปรึกษาทันที
4. **จำลองแจ้งเตือน LINE Notify:**
   - หน้าต่างจำลองสมาร์ทโฟนแจ้งเตือนเข้า LINE ครูที่ปรึกษาพร้อมรายละเอียดและลิงก์ด่วน
5. **บันทึกการดูแลช่วยเหลือรายกรณี (Care & Intervention Logs):**
   - บันทึกการพูดคุยกับผู้ปกครอง, เยี่ยมบ้าน, ทุนฉุกเฉิน, เรียนเสริม และผลการติดตาม
6. **แบบรายงานทางการสำหรับผู้บริหาร (Printable Official Academic Report):**
   - ฟอร์แมตเอกสารราชการสถานศึกษา พร้อมตราสัญลักษณ์วิทยาลัยการอาชีพเวียงสระ และช่องลงนาม
